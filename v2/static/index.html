УПРАВЛЕНИЕ СЕРВЕРАМИ

Агенты VPS

После первоначальной установки связь только через защищённый исходящий HTTPS. Управление Docker, службами, логами, Nginx и TLS без SSH.

Для работающих VPS без агента доступна однократная установка через SSH. После регистрации агента SSH-пароль для управления нодой не требуется и не сохраняется. Сервер панели Remnawave не изменяется.

Подключённые серверы

Агент отправляет heartbeat примерно каждые 15 секунд

TLS / СЕРВЕРЫ

Сертификаты нод

Certbot на каждой VPS. Проверка и обновление через агент VPS и API Remnawave.

Сертификаты выпускаются и хранятся на самих VPS в /opt/nginx/certs. Дополнительные папки на сервере панели не создаются. Для совместимости с Remnawave сертификат передаётся в профиль через API. Автоматическая синхронизация включается отдельно для каждой ноды.

Состояние сертификатов

Автопроверка каждые 6 часов

Безопасный предпросмотр

Действующие VPN-конфиги и ключи не изменяются при редактировании библиотеки или создании плана моста. Применение будет подключено отдельно после проверки совместимости и отката.

Глубокая проверка сетевой доступности из регионов потребует независимых измерительных узлов и не подменяется проверкой с одного VPS.

Добавить сервер

      

    

      
Сначала проверим чистый VPS по SSH, затем установим Docker, Nginx, TLS и Remnawave Node и создадим профиль в панели.

      

        

          

        

          

        

          

        
        

          

        
Установка только на пустой Ubuntu/Debian. DNS домена должен указывать на указанный IPv4. Порт 2222 разрешается только IP панели. Пароль SSH не сохраняется в базе.
Первый установщик ещё не проверен на настоящем VPS. Используй только пустую тестовую машину. При сбое возможна частичная установка без автоматического отката.
