⚙ Настройки проекта

Новый проект

Домен панели нужен для API. Исходящий IP используется только для доступа панели к ноде. Если его не знаешь, можно подтвердить A-запись домена перед установкой; это безопасно только если она совпадает с исходящим адресом панели.

Подключение Remnawave API

Сначала сохрани проект с HTTPS-доменом и API-токеном. Затем получи ключ ноды и выбери профиль, inbound-ы. Все настройки сохраняются для новых VPS проекта.

Шаблоны установки

Шаблон применяется только к выбранному проекту. Изменение шаблона не меняет уже работающие VPS.

⚙ Настроить шаблон

Новый шаблон

Привязка Remnawave для шаблона

По умолчанию наследуется Config Profile проекта. Для Hysteria/XHTTP можно выбрать собственный профиль и inbound-ы, не изменяя глобальные настройки проекта.

◫ Предварительный просмотр Xray

Предварительный просмотр Xray

Шаблон не устанавливает inbound в Remnawave. Менеджер не заменяет настройки Xray в панели.
